# 三项能力升级工作记录

更新：2026-10-17。状态：三项能力已接入正式 Agent 与 Studio；通过项和随机场景中的失败项均以实际运行记录为准。

## 已接入

- 真实腕部 RGB-D → VLM 像素目标框 → 深度点云 → 粗定位/两帧精确定位 → 抓取前复查。
- 简单物体快速顶抓；复杂物体三视角点云、分层宽度、窄杆侧抓；LLM 仅选择本地可行候选。
- 固定 Operator Frame、米制边缘间距、多约束放置、释放后视觉测量。
- 有限步长/速度/接触力的物理推移，以及重新抓取/重新放置策略。
- Studio 显示真实定位、抓取策略、空间测量、恢复事件；观察镜头独立于腕部传感器。
- 默认感知相机已改为 wrist，更新 config/agent.json；gantry 保留为显式配置选项。

## 本轮修复

- MuJoCo 动态更新感知障碍框时同步 broad-phase 边界，防止漏检。
- 裁切画面不能使障碍物高度下降，也不能获得精确定位锁。
- 新侧视可以补充初次俯视看不到的物体高度；持物后保持已测尺寸。
- 推移使用固定高度的绝对目标，避免每一步将伺服下垂累积进下一步。
- 放置末段增加 XYZ 视觉反馈修正；推移前检查工具可达性和避障。
- 侧抓候选评估完整预抓路径，复用已检查路径；按接触层高度计算侧方净空。
- 禁止对裁切/灰色障碍物表面进行盘子圆形外推，避免虚构大障碍物。
- 当前任务内保留已观察支撑面，避免长任务中仍静止的桌面证据超时消失。
- 跟踪丢失允许低频重新定位；搜索视角数和跟踪 IoU 使用配置。
- 多视角计数来源改为实际扫描事件，即使后续抓取失败也记录。
- 已测量重叠且同高度的同色视觉片段合并为同一物体 ID，避免重新抓取时把一个物体当成两个障碍。
- 侧抓松爪后的侧向脱离使用单独规划模式；仅对已释放目标的夹爪手掌保守包围盒重叠放宽，实际接触仍由物理监控拦截。
- 推移预算不足以消除剩余视觉误差时提前改为重新抓取，防止在低位发起无效推移。
- 单侧摩擦修正只用于新版机械臂控制器，旧版执行不再受到新版物理规则影响。
- 侧抓释放后的最终验收要求至少两个新鲜腕部视角融合轮廓；视角不足明确失败，防止单视角边缘低估导致假成功。重新抓取的顶抓宽度使用外侧 0.5% 点并留 3 mm 夹爪余量。
- 独立评分现在对圆柱、胶囊、球和椭球使用各自的真实旋转边界公式，不再用旋转立方体近似圆柱。对「保持竖直」约束，结束验收检查实测顶面法向。
- 多次重新放置时，下一次规划使用上次释放后的视觉间距残差补偿；原始任务目标和最终验证仍保持用户要求的间距。已用于 15 cm 大误差成功回归。
- 杯子遮挡盘子时先有界侧移腕部，以新鲜 RGB-D 再锁定盘子；释放后保留抓前完整测得的杯子高度，避免把下方盘面或桌面并入杯子高度。
- 多视角融合后的真实外轮廓保存为世界坐标；释放后单视角测得的质心可以漂移，但不能把已证实的轮廓一起平移。物理放置的假设位置仍按规划位移转换。
- 预抓末段允许规划器的手掌保守包围盒与目标相交，解决精确贴近时的假阳性；真实物理碰撞和运行时安全监控仍独立检查。
- 将同色、同高度且投影高度重叠的固定障碍碎片合并；即使碎片被误分类为可移动瓶子，也保留已测完整固定障碍，防止碰撞代理虚增。
- 狭长 RGB 片段不得首次外推为完整圆盘；完整静止盘面在后续相近视角中保留已测大小，不让微小视角误差逐帧膨胀边缘。
- 数值间距恰在视觉验收容差边界附近时，可以追加独立腕部视角并融合一致的测量；两视角分歧过大仍保留原失败结论。
- 放置下降时若接触卸载，只有重新观察确认物体稳定且落在预期支撑高度，才放开夹爪并进入后续视觉纠正。
- 抓取区域只在用户明确提出时成为任务约束；语言模型凭物体类别推断的“抓把手”不再排除已测可行的杯身/顶抓候选。放置中失去夹持后先退开，再用正式的双帧视觉关系验收检查物体是否已经稳定到位；若未到位，沿现有纠正策略处理。
- 持物寻找被遮挡的参考物时，将侧移分段，每段后立即尝试两帧精确锁；随机蓝盒种子从原先 9 cm 整段侧移时掉落，变为 2.25 cm 后锁定参考物。后续低位路径仍因灰色障碍无安全解，系统保持失败且 0 意外接触。
