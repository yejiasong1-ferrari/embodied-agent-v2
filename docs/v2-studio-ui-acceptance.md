# Robot Studio 本地 UI 验收

日期：2026-10-16。以下结果来自原生 PySide6 窗口、实际 MuJoCo 和正式 V2 Agent。

## 1. 入口和运行

在仓库根目录执行 `.venv/bin/python run_studio.py`。默认腕部 RGB-D，在线模式使用环境中配置的模型服务。`--offline` 使用本地视觉回退；`--required-llm` 强制在线任务解释。双击仓库中的启动 command 文件也可打开。

## 2. 工作区布局

主要区域为真实仿真工作场景，右侧为任务/视觉/事件，底部为指令输入和执行按钮。1280×800 与 1440×900 布局检查通过。保留当前中文 Robot Studio 风格。

## 3. 旋转、平移、缩放

拖动旋转，Shift+拖动平移，滚轮缩放。五种预设 Perspective/Top/Front/Left/Right，R 复位。原生鼠标/键盘事件测试通过。

## 4. 专注模式

F 进入专注模式，Escape 返回；输入框内的字母不会触发场景快捷键。专注模式中停止按钮可用。

## 5. 镜头与机械臂隔离

观察镜头只改变渲染参数。实测旋转前后机器人 qpos、控制输入、感知相机位置、WorldModel 均未变化。运行中持续旋转观察镜头，最终 Operator Frame 左侧关系仍通过验收。

## 6. 真实任务入口

UI 使用 `studio.runtime.AgentWorker` 调用 `agent.embodied_agent.EmbodiedAgent`。并非旧控制脚本回放或动画。正式任务输入、状态、日志、传感图像来自同一次 Agent 运行。

## 7. 完整在线执行

`outputs/studio_checks/metric.json`，任务 `task_20261016T102039_dcff1f4f`：

- 指令：把蓝色盒子放到绿色积木左边8cm。
- 实际完成抓取、抬起、放置、退开和两帧视觉稳定性验收。
- 191.22 秒；12 次真实模型调用，其中 10 次视觉定位；0 意外接触。
- 最终测量边缘间距 7.135 cm，误差 0.865 cm，满足配置的 ±1 cm。
- 不能将此结果描述为恰好 8 cm，不能据此推断所有物体/任务都能成功。

## 8. 完成状态真实性

完成标志由最终视觉关系与稳定性验证驱动；发出松爪命令本身不算完成。失败/停止任务不会显示成功。metric 测试检查了 UI 与真实 result、validator 的一致性。

## 9. 视觉面板

显示同一感知流的 RGB、Detection、Depth，图像可以放大。缺失图像显示不可用；旧图像显示滞后；历史记录明确显示 REPLAY。面板 22 项检查通过。

## 10. 易懂日志

中文阶段说明覆盖定位、靠近、多视角扫描、抓取、放置、测距、推移、重新抓取和失败恢复。开发者模式可查看原始 WorldModel、遥测、模型事件。

## 11. 日志滚动

手动向上滚动后不被新事件拉回底部；提示有新事件，点击后恢复跟随。筛选和开发者原始证据显示检查通过。

## 12. 响应性

渲染、任务、GUI 独立工作。metric 测试中模型等待阶段收到 263 帧、运动阶段 939 帧，GUI 定时器最大间隔约 0.276 秒。该数值是本次机器负载下的测量，不是固定性能保证。

## 13. 停止

stop-llm 测试 25 项通过；停止派发约 6.3 ms。stop-motion 测试 27 项通过；真实抓取抬起后停止派发约 5.7 ms。最终状态 USER_STOP。派发耗时不等于网络请求立即返回。

## 14. 重建与历史

reset 测试含关闭检查共 28 项通过：空闲可重建，重建过程中禁用执行，运行中重建按钮禁用，新仿真可接收新任务。历史结果与磁盘 JSON 一致，历史图像来自真实运行。

## 15. 证据与当前限制
